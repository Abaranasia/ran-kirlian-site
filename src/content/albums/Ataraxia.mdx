Ataraxia is a Woomh EP created by Ran Kirlian that comprises 4 electronic tracks hard to be catalogued into any ambient style beyond experimental but consistently fitting the Woomh concept. It collects music created between 2012 and 2013 using both software and hardware synthesizers, samplers and effect tools and building an alternative sonic palette to the most typical Kirlian textures.
